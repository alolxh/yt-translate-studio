# YT Translate Studio

> **English summary:** A Chrome extension that translates YouTube titles, descriptions, and subtitles right inside YouTube Studio. This repository hosts the optional subtitle server component — download it from **Releases**.

Tiện ích Chrome giúp dịch tiêu đề, mô tả và phụ đề YouTube ngay trong YouTube Studio.

## Máy chủ phụ đề (thành phần riêng)

Tính năng lấy phụ đề cần một máy chủ nhỏ chạy trên máy Windows của bạn:

1. Tải gói mới nhất tại mục **Releases** của repo này (file `yt-translate-subs-server-*.zip`).
2. Giải nén vào một thư mục tự chọn, chạy `start-subs-server.bat`.
3. Điền địa chỉ máy chủ (xem file `endpoint.txt` trong thư mục máy chủ) vào trang Tùy chọn của tiện ích và bấm **Kiểm tra**.

Chi tiết cài đặt xem file `README-CAI-DAT.md` bên trong gói.
